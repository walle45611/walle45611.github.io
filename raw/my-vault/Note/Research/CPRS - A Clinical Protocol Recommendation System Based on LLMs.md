# CPRS: A Clinical Protocol Recommendation System Based on LLMs

## 初讀摘要

- CPRS 處理的是臨床試驗方案與患者的匹配推薦，不是直接產生患者治療處方。
- 系統先利用知識圖譜篩出具有相似特徵的候選試驗，再以 GPT-4 的語意能力排序與提供推薦，並和 SBERT 類模型比較。
- 原文報告 GPT-4 在方案相似度排序與推薦上的優勢；閱讀時應核對候選篩選、患者資訊及評估方式，避免把排序表現延伸為治療效果。
