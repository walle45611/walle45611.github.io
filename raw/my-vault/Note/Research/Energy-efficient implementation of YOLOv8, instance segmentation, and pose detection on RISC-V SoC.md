# Energy-efficient implementation of YOLOv8, instance segmentation, and pose detection on RISC-V SoC

## 初讀摘要

- 研究提出以 RISC-V 為基礎的視覺 SoC，執行 YOLOv8 物件偵測、實例分割與姿態偵測。
- 結合神經網路層級最佳化、分段線性近似、8-bit 定點量化與硬體設計，使端到端推論適合資源受限的平台。
- 原文在固定輸入解析度與特定硬體條件下報告即時效能及能效優勢；比較時需一起看任務、精度、解析度與功耗，不能只比較 FPS。
