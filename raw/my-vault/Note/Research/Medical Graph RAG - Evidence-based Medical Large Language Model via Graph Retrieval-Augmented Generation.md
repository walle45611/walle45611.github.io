# Medical Graph RAG: Evidence-based Medical Large Language Model via Graph Retrieval-Augmented Generation

## 初讀摘要

- MedGraphRAG 希望讓醫療回答能結合使用者文件與可信醫學來源，並保留證據連結。
- 提出 Triple Graph Construction 與 U-Retrieval，結合由上而下精確檢索及由下而上的回答整合，以平衡整體脈絡與局部證據。
- 原文在醫療 QA、健康事實核查與長文生成評測報告改善；可追溯來源是其重點，但 benchmark 結果仍不是臨床安全性驗證。
