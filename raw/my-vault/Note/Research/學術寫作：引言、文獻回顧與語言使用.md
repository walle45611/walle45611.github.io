# 學術寫作：引言、文獻回顧與語言使用

## 引言：從研究問題走向研究目的

引言（Introduction）應簡要交代研究主題、動機、相關文獻、知識缺口與研究問題，讓讀者理解研究的重要性與方向。文獻背景應精簡且切題，避免在引言中全面鋪陳整個領域。

| 要素 | 要回答的問題 |
| --- | --- |
| 問題（Problem） | 發生了什麼問題？ |
| 研究理由（Rationale） | 為什麼這個問題重要？ |
| 研究目的（Purpose） | 本研究打算如何處理這個問題？ |
| 知識缺口（Knowledge Gap） | 現有研究還有哪些不足、不一致或爭議？ |
| 研究問題與目標（Research Questions and Objectives） | 本文想回答什麼問題、達成什麼目標？ |
| 研究情境（Context） | 研究是在什麼情境下進行？ |
| 方法或途徑（Method or Approach） | 研究採用了什麼方法？ |
| 全文結構（Overall Structure） | 全文接下來如何安排？ |

研究旨在擴展特定主題的知識，並處理具體的知識缺口、不一致（inconsistencies）或爭議（controversies）。說明缺口時，也應交代本研究的主要貢獻，以及它與缺口的關係。

寫作提醒：

- 避免不必要的技術術語（technical jargon）；需要使用時，清楚定義關鍵詞與構念（constructs）。
- 說明研究的學術重要性，並以適當文獻支持。
- 全文結構只需簡短概述論文的行文順序。
- 引言可在寫作後期再完成或修訂，與摘要（Abstract）一樣，待全文內容確立後較容易掌握重點。

研究目的應直接說明研究探討什麼，讓內容具體清楚，可使用以下句型：

> This paper investigates …

例如，與其籠統寫「處理模型可靠性的問題」，可以具體寫「探討檢索增強是否能降低模型回答中的事實錯誤」。使用 “This study addresses the problem of …” 時，也應明確指出所處理的問題。

**引言開頭先介紹主題，不要立刻列出研究問題與假說。** 先交代背景、重要性與相關概念，再透過文獻與知識缺口引出研究問題、目標或假說。

行文順序：**背景與重要性 → 相關研究 → 知識缺口 → 研究問題、目標或假說**。

## 文獻回顧：以主題整合研究

文獻回顧（Literature Review）的核心是**綜合相關研究的發現（synthesis）**，建立研究脈絡，而非逐篇羅列摘要。內容應精簡、切題，說明本研究在較廣泛研究領域中的位置與重要性。

文獻回顧應涵蓋：

1. 本研究在領域中的定位與意義。
2. 關鍵概念與研究構念的定義。
3. 相關既有研究發現的綜合整理。
4. 先前研究使用的方法與評估方式。
5. 支持本研究問題、目標或假說的理論依據。

**組織方式**：依相關主題或具體議題安排內容，提供清楚的回顧脈絡。標題應具體，避免只用單一詞彙作為標題；可運用相關圖示輔助比較，並在文字中解釋比較結果。結尾可簡要銜接研究動機與假說。

**概念與定義**：不要直接照抄定義，應理解後用自己的文字表述，並連結研究情境。技術術語應有文獻依據，關鍵概念宜在首次提及時說明；不要把文獻回顧寫成逐條列出的定義清單。

**屬性與因素（Attributes or Factors）**：不要僅列舉屬性或影響因素，還應加以歸納與總結。

**相反觀點（Opposing Viewpoints）**：清楚說明不同觀點的差異，簡要交代相反主張，並說明接受或不接受該觀點的理由。

**可讀性**：表達應清楚易讀，盡量讓非學術背景的讀者也能理解；避免堆疊術語，必要術語則加以解釋。

## 引用：適當支持論述

常見引用問題包括：

- 錯誤歸屬（misattribution）：把觀點或發現歸給錯誤的來源。
- 重複引用（repeatedly）：反覆引用而未增加實質內容。
- 對過於基本的內容引用過多（over-citing）。
- 使用太多直接引文（quotations），使自己的綜合論述不足。
- 隱藏事實：選擇性引用或省略重要資訊，使讀者對原研究產生誤解。

## 主動與被動語態

學術英文不要求全篇使用被動語態（passive voice）。一般優先採用主動語態（active voice），尤其在引言與討論（Discussion）中提出主張、進行論證時，應讓行動或主張的責任歸屬清楚。

適合使用被動語態的情況：

1. 行動執行者（performer）未知、無關緊要，或已經顯而易見。
2. 行動本身比執行者更重要。
3. 行動的承受者（recipient）才是段落的主要討論對象。

避免通篇使用被動語態，以免讓讀者不清楚由誰執行或負責。

## 時態使用

| 時態 | 用途 |
| --- | --- |
| 現在式（Present Tense） | 表示被接受的事實。 |
| 現在完成式（Present Perfect Tense） | 描述從過去延續至今的累積。 |
| 過去式（Past Tense） | 描述特定一篇論文中的研究。 |

應依句子要表達的時間與內容選擇時態。
