# 學術期刊入門：出版商、索引、分區與論文類型

## 先分清楚：這些名稱在描述不同事情

讀論文或準備投稿時，常會看到「IEEE、SCIE、Q1、IF、Review」放在一起。它們分別描述出版者、收錄情況、期刊排名、引用指標與文章類型，不能排成同一條高低順序。

| 層次 | 回答的問題 | 例子 |
| --- | --- | --- |
| 出版商／出版組織（Publisher） | 誰負責出版？ | IEEE、ACM、Elsevier、Springer Nature |
| 期刊（Journal） | 文章刊登在哪一本刊物？ | 某一本有固定名稱與 ISSN 的學術期刊 |
| 索引／資料庫（Index / Database） | 哪個系統收錄它？ | SCIE、SSCI、ESCI、Scopus |
| 期刊指標與分區 | 在哪個年度、哪個學科、按什麼指標排名？ | JIF、JCR JIF Q1、SJR Q2 |
| 論文類型（Article Type） | 這篇文章做什麼？ | Original Article、Review、Letter |

![[Assets/Note/Research/學術期刊入門/學術期刊五個層次.png]]

> [!important] 最重要的觀念
> SCIE、SSCI 是索引名稱；Q1～Q4 是特定排名體系中的四分位；Article、Review 才是文章類型。**期刊層級的指標不能直接當作單篇論文的品質分數。** [Clarivate 的指標使用說明](https://clarivate.com/academia-government/scientific-and-academic-research/research-funding-analytics/journal-citation-reports/)

## 出版商與期刊：誰出版，和在哪裡發表

出版商負責期刊的出版、發行、平台維護等工作；編輯團隊負責學術內容與審稿決策。期刊的擁有者與實際出版商也可能不同，例如學會委託商業出版社出版。

| 出版組織 | 大致性質 |
| --- | --- |
| IEEE、ACM | 專業學會，也從事學術出版 |
| Elsevier、Springer Nature、Wiley | 商業學術出版商 |
| Oxford University Press、Cambridge University Press | 大學出版社 |
| MDPI | 以開放取用期刊為主的出版商 |

同一家出版商旗下有許多期刊，各本期刊的主題、編輯政策、收錄情況與排名可能不同。因此，「IEEE 期刊」不自動代表 SCIE 或 Q1；「Elsevier 期刊」也不是一種統一等級。

開放取用（Open Access，OA）描述的是讀者取得文章的方式。是否收取文章處理費（Article Processing Charge，APC），是出版與費用政策；這些也應與索引、排名分開判斷。

## SCI、SCIE、SSCI、AHCI、ESCI 是什麼

Web of Science（WoS）是 Clarivate 的文獻檢索平台；其中的 **Web of Science Core Collection** 包含不同索引。下表聚焦期刊索引，Core Collection 另外也有會議論文與書籍索引。

| 縮寫 | 英文全名 | 主要意義 |
| --- | --- | --- |
| SCI | Science Citation Index | 歷史名稱，至今仍常被口語用來指科學類索引期刊；正式記錄應依實際查到的索引名稱 |
| SCIE | Science Citation Index Expanded | 自然科學、工程、醫學等領域的期刊索引，包含資工相關期刊 |
| SSCI | Social Sciences Citation Index | 社會科學期刊索引，例如管理、經濟、教育、社會與部分心理學研究 |
| AHCI（也寫作 A&HCI） | Arts & Humanities Citation Index | 人文與藝術期刊索引 |
| ESCI | Emerging Sources Citation Index | 各領域符合 WoS 品質標準的期刊索引；名稱中的 Emerging 不代表只收創刊不久的期刊 |

**SCIE 與 SSCI 主要是學科涵蓋差異，不能理解成誰比誰高一級。** 跨領域期刊可能同時被多個索引收錄。AI 方法、生醫工程研究與教育科技、科技使用行為研究，會因研究問題不同而接觸不同期刊，不能僅憑「用了 AI」決定索引類別。

Clarivate 以 24 項品質標準及 4 項影響力標準評估期刊。符合品質標準的期刊進入 ESCI；符合額外影響力標準後，依領域可進入 SCIE、SSCI 或 AHCI。收錄情況會重新評估，不能把某次查到的狀態視為永久資格。[期刊遴選官方說明](https://clarivate.com/academia-government/scientific-and-academic-research/research-discovery-and-referencing/web-of-science/web-of-science-core-collection/editorial-selection-process/journal-evaluation-process-selection-criteria/)

實務上，聽到「SCI paper」時，要再確認實際指的是哪個索引；自己寫履歷或研究紀錄時，依查核結果寫「SCIE 收錄期刊」更明確。若學校表格使用 SCI 字樣，仍應依該單位的定義填寫。

**TSSCI 是另一套制度。** TSSCI 全名為 Taiwan Social Sciences Citation Index（臺灣社會科學引文索引），與 Clarivate 的 SSCI 不同；臺灣人文領域另有 THCI。不能把 TSSCI 當成 SSCI 的臺灣分支，也不能用名稱推斷某篇文章的原創性。[國科會人文社會科學研究中心：期刊評比收錄](https://www.hss.ntu.edu.tw/zh-tw/thcitssci)

## Q1～Q4、JCR 與 Impact Factor

Journal Citation Reports（**JCR**）是 Clarivate 的期刊分析產品，提供 Journal Impact Factor（**JIF**）、學科分類、排名等資訊。WoS 的索引回答「收錄在哪裡」，JCR 指標回答「引用表現如何」。

Q 是 Quartile（四分位）。以 JCR 的 JIF 分區為例，是按期刊在某年度、某學科中的 JIF 排名位置劃分：

| 分區 | 直覺理解：由前往後的排名位置 | 假設有 200 本期刊，且沒有同名次的簡化例子 |
| --- | --- | --- |
| Q1 | 前 25% | 第 1～50 名 |
| Q2 | 超過 25%，至 50% | 第 51～100 名 |
| Q3 | 超過 50%，至 75% | 第 101～150 名 |
| Q4 | 超過 75%，至 100% | 第 151～200 名 |

**Q1 是期刊的排名分區，不是單篇論文的品質分數。** 同一本期刊在不同年度或學科中，分區也可能不同。

**Impact Factor（JIF，影響因子）** 是觀察期刊文章被引用情況的指標，可作為了解期刊影響力的參考，但不能只靠這個數字判斷一篇論文好不好。

另外，**ESCI 期刊也可能是 Q1**。ESCI／SCIE 表示收錄在哪個索引，Q1 表示排名分區，兩者要分開看。[Clarivate 官方說明](https://clarivate.com/academia-government/blog/journal-citation-reports-2024-simplifying-journal-evaluation/)

## Q1 要確認排名來源

JCR、CiteScore 與 SJR 是不同的期刊評估指標或體系，同一本期刊的分區可能不同。因此看到「Q1」時，要確認是**哪一套排名、哪個年度、哪個學科**，不能直接混用。[CiteScore 說明](https://www.elsevier.com/products/scopus/metrics/citescore)、[SJR 分區說明](https://www.scimagojr.com/journalsearch.php?q=26980&tip=sid)

## 期刊論文與會議論文

依發表管道，常見的論文可以分成兩類：

| 類型 | 發表管道與常見評估方式 |
| --- | --- |
| Journal Paper（期刊論文） | 發表於學術期刊，常參考 SCIE／SSCI 等收錄情況，以及 JCR 分區、JIF 等期刊指標。 |
| Conference Paper（會議論文，簡稱 Conf. Paper） | 發表於學術會議，主要看該會議在領域內的聲譽與是否為公認的頂會；沒有跨領域通用的排名，不能直接套用期刊的 Q1～Q4。 |

資工領域的頂會是重要的研究發表管道，不能一概認為會議論文比期刊論文低一級。部分會議也有評級制度，仍需依所屬領域判斷。

至於 **Original Article（原著研究）、Review（綜述）**，描述的是文章內容與目的，與期刊／會議這種發表管道分類不同。

## 實際查詢與記錄方式

**北商登入**：使用國立臺北商業大學帳號，可由[北商電子資源登入入口](https://eresources.ntub.edu.tw/sendURLApiV3/)登入，使用學校提供的電子資源。

拿到一本期刊名稱後，可以依下列順序查核：

1. **確認期刊身分**：查看完整刊名、ISSN／eISSN、官方網站與出版商，避免同名或改名混淆。
2. **查收錄狀態**：到 [Master Journal List](https://mjl.clarivate.com/) 查 WoS 的實際索引與收錄資訊；若需要證明特定文章被收錄，還要查該篇文獻紀錄及涵蓋年代。
3. **查排名與指標**：在 [JCR](https://jcr.clarivate.com/) 確認年度、學科、JIF、Rank 與 JIF Quartile；CiteScore 與 SJR 則分別到對應平台查詢。
4. **查文章類型**：閱讀文章頁及期刊作者指南；不要把索引或分區填進 Article Type。
5. **保留查核依據**：記錄查詢日期與來源。若用於畢業、獎勵或申請，另外核對單位指定的年度、排名體系及收錄資格。

以下是**虛構教學範例，不代表任何真實期刊的排名**：

| 欄位 | 記錄範例 |
| --- | --- |
| Journal | Journal X |
| Publisher | 出版組織 A |
| WoS Index | SCIE |
| Metric / Data Year | JCR JIF，2024 資料年度 |
| Category | Computer Science, Artificial Intelligence |
| Rank / Quartile | 35 / 200；Q1 |
| JIF | 5.0 |
| Article Type | Research Article |
| 查詢日期與依據 | 2026-09-18；MJL 與 JCR 對應紀錄 |

另一個學科分類若為 150 / 400，便可能是 Q2；這不會使前一個分類的 Q1 失效。需要比較時，應選同一套指標、同一年度與可比較的學科分類。

閱讀文獻時，可以把索引與排名當作了解出版背景的線索，接著回到文章本身：研究問題是否重要、方法是否合理、證據是否支持結論，以及限制是否交代清楚。
