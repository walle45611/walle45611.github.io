# 第一章整理：線性方程組與向量空間基礎

## I. 核心概念與向量空間入門

### A. 向量與線性關係

| 概念                                 | 定義/描述                                                                                           |
| :--------------------------------- | :---------------------------------------------------------------------------------------------- |
| **向量 (Vector)**                    | 在 $R^n$ 中具有 $n$ 個實數分量的序列。                                                                       |
| **線性組合 (Linear Combination)**      | 將向量乘以純量後相加的結果，例如 $\sum c_i\mathbf{v}_i$。                                                        |
| **張成空間 (Span)**                    | 一組向量 $\mathbf{v}_i$ 所有可能的線性組合所形成的集合，記作 $\operatorname{span}{\mathbf{v}_i}$。                     |
| **線性獨立 (Linear Independence, LI)** | 若 $\sum c_i\mathbf{v}_i=\mathbf{0}$ 僅有零解 $c_i=0$ (全部)。如果一個 $m \times n$ 矩陣的秩 $r=n$，則其行向量是線性獨立的。 |
| **子空間 (Subspace)**                 | 向量空間 $V$ 的一個非空子集，且對**加法**與**純量乘法**保持封閉性 (Closure)。                                              |
| **基底 (Basis) 與維度 (Dimension)**     | 既能生成 (Span) 整個空間，且集合內元素線性獨立的最小生成集。向量的數量即為該空間的維度。                                                |

### B. 矩陣與基本形式

| 概念                                         | 描述                                                                   |
| :----------------------------------------- | :------------------------------------------------------------------- |
| **階梯形 (Echelon Form, REF)**                | 高斯消去法（Gaussian Elimination）的最終結果 $U$，其中主元（Pivot）是每列的第一個非零元素，且零列在最下方。 |
| **簡化階梯形 (Reduced Row Echelon Form, RREF)** | REF 的基礎上，所有主元均為 1，且主元所在列的其他元素均為 0，記作 $R$。                            |
| **秩 (Rank, $r$)**                          | 矩陣中主元（Pivot）的數量。這等於行空間的維度，也等於列空間的維度。                                 |

### C. 四個基本子空間

給定 $A$ 為 $m \times n$ 矩陣，其秩為 $r$：

| 空間名稱                      | 符號/定義                                                                                                    | 維度    |
| :------------------------ | :------------------------------------------------------------------------------------------------------- | :---- |
| **行空間 (Column Space)**    | $\mathcal{C}(A)$ 或 $\operatorname{Im}(A)$。由 $A$ 的列向量的所有線性組合組成。                                           | $r$   |
| **列空間 (Row Space)**       | $\mathcal{C}(A^\top)$ 或 $R(A)$。由 $A$ 的行向量的所有線性組合組成。                                                      | $r$   |
| **零空間 (Nullspace)**       | $\ker(A)$ 或 $N(A)$。所有滿足 $A\mathbf{x}=\mathbf{0}$ 的 $\mathbf{x}$ 向量的集合。                                   | $n-r$ |
| **左零空間 (Left Nullspace)** | $N(A^\top)$。所有滿足 $A^\top \mathbf{y}=\mathbf{0}$ (即 $\mathbf{y}^\top A=\mathbf{0}$) 的 $\mathbf{y}$ 向量的集合。 | $m-r$ |

**秩–零度定理 (Rank-Nullity Theorem)**：$\dim \ker(A)= n-\operatorname{rank}(A)$，即 $n = r + (n-r)$。

## II. 線性方程組的結構 (Ax=b)

### A. 齊次方程組 (Homogeneous System: $A\mathbf{x}=\mathbf{0}$)

- 解集為零空間 $\ker(A)$。
- 幾何上，解集是通過原點的一個子空間。
- $A\mathbf{x}=\mathbf{0}$ 總是有至少一個解，即零解 $\mathbf{x}=\mathbf{0}$。
- 若 $r < n$，則存在無限多解（即非零解），因為有 $n-r$ 個自由變數。

### B. 非齊次方程組 (Non-homogeneous System: $A\mathbf{x}=\mathbf{b}$)

- **所有解的結構：** 如果存在解 $\mathbf{x}_p$，則所有解都可以表示為一個**特解** $\mathbf{x}_p$ 加上零空間中的所有向量 $\mathbf{x}_n$。 $$\mathbf{x} = \mathbf{x}_p + \ker(A)$$

### C. 解的存在性與唯一性 (Rouché–Capelli 定理)

判斷 $A\mathbf{x}=\mathbf{b}$ 是否有解，取決於 $\mathbf{b}$ 是否在 $A$ 的行空間 $\mathcal{C}(A)$ 內。此判斷依賴矩陣 $A$ 與增廣矩陣 $[A|\mathbf{b}]$ 的秩：

1. **無解 (No Solution)**：
    - $\operatorname{rank}(A) < \operatorname{rank}([A|\mathbf{b}])$。
    - 這表示 $\mathbf{b}$ 不在 $\mathcal{C}(A)$ 內。
2. **唯一解 (Unique Solution)**：
    - $\operatorname{rank}(A) = \operatorname{rank}([A|\mathbf{b}]) = n$ (矩陣具有滿列秩，Full Column Rank)。
3. **無限多解 (Infinitely Many Solutions)**：
    - $\operatorname{rank}(A) = \operatorname{rank}([A|\mathbf{b}]) < n$。
    - 這意味著存在 $n-r$ 個自由變數。

## III. 方陣的可逆等價條件 ($A$ 是 $n \times n$)

對於方陣 $A$，以下條件是等價的 (The Invertible Matrix Theorem)：

- $A$ **可逆** $\iff A$ **非奇異** (Nonsingular)。
- $\det A \neq 0$。
- $\operatorname{rank}(A)=n$ (滿秩)。
- $A\mathbf{x}=\mathbf{0}$ 只有零解 $\mathbf{x}=\mathbf{0}$。
- $A$ 列等價於單位矩陣 $I$ ($R=I$)。
- $A$ 是有限個初等矩陣之積。

如果 $A$ 可逆，則唯一的解為 $\mathbf{x} = A^{-1}\mathbf{b}$。

## IV. 計算方法與實戰步驟

### A. 求解 $A\mathbf{x}=\mathbf{b}$ 的步驟

1. **形成增廣矩陣**：構造 $[A|\mathbf{b}]$。
2. **高斯消去 (Gaussian Elimination)**：將 $[A|\mathbf{b}]$ 化簡到 REF 或 RREF。
3. **判斷秩與相容性**：
    - 檢查是否存在 $0 = c$（其中 $c \neq 0$）的矛盾式。若存在，則無解。
    - 若有解，確定秩 $r$、**主元變數** (Pivot Variables) 和 **自由變數** (Free Variables, $n-r$ 個)。
4. **找到特解 $\mathbf{x}_p$**：設定所有自由變數為零，並利用回代法 (Back-substitution) 求解主元變數。
5. **找到零空間基底 $\ker(A)$**：繼續下一步驟。

### B. 求零空間 $\ker(A)$ 基底的步驟

1. **解齊次系統**：對 $[A|\mathbf{0}]$ 進行消去，得到 $R\mathbf{x}=\mathbf{0}$。
2. **生成特殊解**：對每一個自由變數：
    - 將該自由變數設為 1，其他自由變數設為 0。
    - 解 $R\mathbf{x}=\mathbf{0}$ 得到對應的主元變數的值。
3. **結果**：得到的 $n-r$ 個特殊解向量即為 $\ker(A)$ 的基底。

### C. 找行空間 $\mathcal{C}(A)$ 和列空間 $\mathcal{C}(A^\top)$ 基底的步驟

- **列空間基底**：$A$ 經高斯消去到 $R$ (RREF) 後，**非零列**構成 $\mathcal{C}(A^\top)$ 的一組基底。
- **行空間基底**：找到 $R$ 中的**主元列** (Pivot Columns)。原矩陣 $A$ 中對應這些主元列的**列向量**，構成 $\mathcal{C}(A)$ 的一組基底。

## V. 常見題型模板與速查清單

| 題型模板         | 核心操作與目標                                                                                                                                                                                                     |
| :----------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **「解並分類」**   | 先計算 $\operatorname{rank}(A)$ 和 $\operatorname{rank}([A\mathbf{b}])$，確定解的類型（無解、唯一解、無限多解），再給出特解 $\mathbf{x}_p$ 和零空間解 $\mathbf{x}_n$。                                                                          |
| **「證明解集」**   | 證明所有解形如 $\mathbf{x}=\mathbf{x}_0+\mathbf{u}$，其中 $A\mathbf{x}_0=\mathbf{b}$ 且 $\mathbf{u} \in \ker(A)$。驗證 $A(\mathbf{x}_0+\mathbf{u}) = A\mathbf{x}_0 + A\mathbf{u} = \mathbf{b} + \mathbf{0} = \mathbf{b}$。 |
| **「判可逆性」**   | 檢查任何一個等價條件，例如 $\det A \neq 0$ 或 $\operatorname{rank}(A)=n$。                                                                                                                                                 |
| **「找零空間基底」** | 將 $A$ 化簡到 RREF $R$，找出自由變數，並構造特殊解。                                                                                                                                                                           |
| **「同解性」**    | 行等價操作（Elementary Row Operations）不改變線性方程組的解集 $\mathbf{x}$。                                                                                                                                                   |

### 速查清單總結

- **核心步驟**：先透過高斯消去**看秩 $r$**。
- **有解條件**：有解才討論特解 $\mathbf{x}_p$ 和零空間 $\mathbf{x}_n$。
- **方陣唯一解**：方陣 $A_{n\times n}$ 有唯一解 $\iff$ 每行（或每列）都有主元 $\iff \det A \neq 0 \iff \operatorname{rank}(A)=n$。
- **零空間維度**：零空間維度 = 變數數量 $n$ − 秩 $r$ (即自由變數的數量)。
