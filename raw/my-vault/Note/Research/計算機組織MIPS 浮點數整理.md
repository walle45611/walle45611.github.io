## 1) 暫存器架構與重點

- 整數暫存器：32 個 `$0~$31`（zero, at, v0–v1, a0–a3, t0–t9, s0–s7, k0–k1, gp, sp, fp, ra）。
    
- 浮點暫存器：32 個 `$f0~$f31`（屬於 Coprocessor 1, FP）。
    
    - 單精度 `.s`：每個 `$fX` 放 32-bit 浮點數。
        
    - 雙精度 `.d`：**偶數+下一個奇數** 成對，如 `$f0/$f1`, `$f2/$f3`, …, `$f30/$f31`。
        
- 暫存器跨區搬移：`mtc1`（整數→浮點）, `mfc1`（浮點→整數）。

## 3) 指令分類與範例

### 算術（Arithmetic）

- 單精度：`add.s`, `sub.s`, `mul.s`, `div.s`
    
    - 例：`add.s $f2, $f4, $f6` // $f2 = $f4 + $f6
        
- 雙精度：`add.d`, `sub.d`, `mul.d`, `div.d`
    

### 比較（Compare）+ 狀態旗標（FP condition bit）

- `c.lt.s $f2, $f4` // 若 $f2 < $f4，設 FP 条件旗標=1
    
- `c.le.s $f2, $f4` // 若 $f2 ≤ $f4，設 FP 条件旗標=1
    

### 分支（由 FP 条件旗標決定）

- `bc1t label` // flag=1 跳
    
- `bc1f label` // flag=0 跳
    

### 資料搬移（記憶體 <-> 浮點暫存器）

- `lwc1 $f2, imm($rs)` // 載入 32-bit 到 FPR
    
- `swc1 $f2, imm($rs)` // 存回 32-bit
    
- 對 double 的載入/存回：`ldc1`, `sdc1`（依架構支援）
    

### 暫存器間搬移（整數<->浮點）

- `mtc1 $rt, $fx` // GPR -> FPR（位元型式搬移，不做數值轉換）
    
- `mfc1 $rt, $fx` // FPR -> GPR（位元型式搬移）
    
- 浮點型別轉換：`cvt.s.d`, `cvt.d.s`, `cvt.w.s`, `cvt.w.d` 等

## 4) 地址模式（挑重點）

- `lwc1/swc1/ldc1/sdc1`：**Base + Offset（位址＝$rs + 立即值）**。
    
- 浮點算術與比較（`add.s`, `c.lt.s` 等）：**Register addressing**（運算元來自 FPR）。
    
- 浮點分支（`bc1t/bc1f`）：**PC-relative**。
    
- 一般跳躍對照：
    
    - `j target`, `jal target`：**Pseudo-direct**。
        
    - `jr $rs`, `jalr $rd, $rs`：**Register**。
        

---

## 5) 機器碼格式速記

- 多數浮點算術/比較屬 **R 型**（含 `fmt` 指定精度、`funct` 指定操作）。
    
- `lwc1/swc1` 等屬 **I 型**（`opcode` 指示載入/存回）。
    
- `bc1t/bc1f` 屬 **I 型分支**（含 16-bit offset）。
    

---

## 6) 常見易混點

- FPR 與 GPR 互不相容，**不得直接混用**。
    
- 需要數值語意轉換時，請用 `cvt.*.*`，`mtc1/mfc1` 只有位元搬移語意。
    
- 雙精度請以 **偶數/奇數** 成對使用，避免未對齊造成的錯誤。
