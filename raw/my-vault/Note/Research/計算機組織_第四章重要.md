## MIPS R-type 指令：以 `add` 為例

### 指令格式
- **op (Operation code)**：6 位元，`add` 指令為 `000000`  
- **rs (Source register 1)**：5 位元，第一來源暫存器  
  - 例：`add $t1, $s1, $s2` 中 `$s1=17`  
- **rt (Source register 2)**：5 位元，第二來源暫存器  
  - 例：`add $t1, $s1, $s2` 中 `$s2=18`  
- **rd (Destination register)**：5 位元，目的暫存器，存放運算結果  
  - 例：`add $t1, $s1, $s2` 中 `$t1=9`  
- **shamt (Shift amount)**：5 位元，移位量，對 `add` 通常為 `00000`  
- **funct (Function code)**：6 位元，決定 ALU 執行的具體操作  
  - `add` → `100000` (十進位 32)
### 單一週期處理器的資料路徑操作

1. 指令擷取與 PC 增量
	- 從指令記憶體取出指令  
	- PC ← PC + 4  
 2. 暫存器讀取與控制訊號
	- 從暫存器檔案讀出 rs、rt 的值  
	- 主控制器輸出控制訊號：  
		  - **RegDst = 1** → 寫入 `rd`  
		  - **ALUSrc = 0** → 第二運算元來自暫存器 (rt)  
		  - **MemtoReg = 0** → 回寫值來自 ALU  
		  - **RegWrite = 1** → 開啟暫存器寫入  
		  - **MemRead = 0**、**MemWrite = 0** → 不訪問資料記憶體  
		  - **Branch = 0** → 非分支  
		  - **ALUOp = 10** → 由 funct 欄位決定 ALU 功能  
3. ALU 運算
	- ALU 根據 funct 執行加法  
	- 例：`$s1 + $s2`  
4. 結果寫回
	- ALU 輸出結果寫入目的暫存器 (`rd = $t1`)
