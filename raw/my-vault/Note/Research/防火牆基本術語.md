## firewall type

防火牆的類型大致可以分為這幾種

- Packet filter
    
	[[Cisco ACL 存取控制清單指南]]
    
    - 缺點 : 沒辦法動態的去做偵測，FTP就沒辦法使用
    
- Proxy server
    
    ![[Assets/Note/Research/防火牆基本術語/04-firewall type - Proxy server.png|04-firewall type - Proxy server.png]]
    
    - 兩個TCP會話
    - 性能低
    - 支持運用很少 HTTP
    - web cache
    - 工作在OSI第七層，最安全防火牆
- Stateful packet filtering
    
    ![[Assets/Note/Research/防火牆基本術語/05-firewall type.png|05-firewall type.png]]
    
    - 會維護一個TCP和UDP狀態訊息列表(stateful sessino flow table)
    - 返回的封包首先查詢stateful session flow table，如果是以前連接過的就算被ACL拒絕也是可以穿越的
    - 性能高，硬體防火牆主流
