- **重構 最簡單的形式是「改變程式碼，但不改變它做的事情」** [1]。
- 提供了一個重構的範例，**將表達式替換為本地變數** [1]。
    - 重構前：`return pow(base, exp / 2) * pow(base, exp / 2);` [1]
    - 重構後：`let result = pow(base, exp / 2); return result * result;` [2]
- 重構有多種可能的原因：
    - **使程式碼更快**（如前面的範例）[2]
    - **使程式碼更小** [2]
    - **使程式碼更通用或可重複使用** [2]
    - **使程式碼更容易閱讀或維護** [2]
- **最後一個原因是如此重要且核心，以至於可以將其等同於好的程式碼** [2]。
- **好的程式碼是人類可讀且易於維護的，並且正確地執行它所設定執行的操作** [2]。
- **由於重構不得改變程式碼正在執行的操作，因此本書重點關注人類可讀且易於維護的程式碼** [2]。
- 由於規則不能保證在所有情況下都能產生好的程式碼，**它們就像訓練輪** [3]。
- 即使程式碼已經遵循了 **DRY（Don't Repeat Yourself，不要重複自己）和 KISS（Keep It Simple, Stupid，保持簡單、愚蠢）原則，** 也可能仍然不夠好[4]。

## 重構概念

### 重構的好處
- 程式碼變更小更快
- 容易維護閱讀
- 更可以重複使用
- 重要的技能、文化和工具

### Code Smell
Code smell 是用來說明什麼樣的程式碼是需要重構的：

- **Code smell 的定義**：Code smell 指的是**程式碼中可能暗示存在問題的徵兆或描述**。這些徵兆不一定是錯誤，但它們**暗示程式碼的設計或結構可能不夠理想**，**需要進一步的評估和可能的重構。**
- **Code smell 的抽象性**：然而，需要注意的是，code smell **本身是比較抽象的概念提供的是一種「感覺」或「直覺」**，而不是明確的、可執行的指令。因此，**判斷某段程式碼是否真的需要重構，仍然需要程式設計師的經驗和判斷。**
## 重構的時機

這本書有說到重構很多都會用到 red-green-refactor 這個方式去做，但是這本書想要分開這個，所以他們採用六個步驟更專註於重構。

### 六個步驟

1. **探索 Explore**
   
   要探索和實驗跟客戶需要開發的東西是否一致。

2. **指定 Specify**
   
   Explore 之後要能準確地知道有什麼需求，最好能夠自動化的方式去驗證。

3. **實作 Implement**
   
   實作程式碼

4. **測試 Test**
   
   通過第二步驟的規格測試

5. **重構 Refactor**
   
   讓你的程式碼能讓下一個或是自己好維護

6. **交付 Deliver**
   
   git push 或是發送 PR

- 要退役的
- 有嚴格要求效能的
- 要請專家協助才能重構

其他都可以重構

## 可讀性 (Readability)
### 重構前

```typescript
function checkValue(str: boolean){
    // Check Value
    
    if (str !== false)
        return true;
    
    else; // otherwise
        return str;
}
```

問題：
- 這段程式碼中裡面會有雙重否定
- 命名不好 str 但是他是個 boolean
- 加了很多無用的註解

### 重構後

```typescript
function isTrue(bool: boolean){
    
    if(bool)
        return true;
        
    else
        return false;
}
```

進一步簡化：

```typescript
function isTrue(bool: boolean){
    return bool;
}
```

## 可維護性 (Maintainability)
- 通常代表我們修改某個功能，程式碼要怎麼去適應現有上下文，且快速輕鬆的。我們所要調查的程度就稱為 Maintainability。
- 如果調查的時間太長有時候也代表了，原先的程式碼維護性不好。
- 改了他會導致其他的地方出現錯誤，不在該 context，稱之 systems fragile，例如說我在修改推薦功能，但是會影響結帳的功能。
- 這種脆弱性通常都是 Global state，這邊的這個 Global 是說大括號以外的。

## Constants Method

- **沒有副作用**（No side effects）—— 只回傳一個值，而不會改變任何狀態。
- **通常回傳一個簡單的常數值（const）**，例如 `bool` 或 `int`。

## 重構模式：統合相似的類別 (Unify similar classes)

### 描述

可以使用這個模式重構 consts method 這種重構後我們叫他 basis，若這個基礎有兩種方法叫做 two-point basis。如果我們要統合 X 個類別的時候，最多需要 (X-1) 點的基礎。

### 步驟

1. **第一階段**：讓所有不是 basis 的變得相通
   1. 在每個版本的方法本體中加上一個 if (true) {} 把現有的方法包住
   2. 用一個表示式替換掉 true
   3. 複製各版本的方法本體，然後加上 else 並到其他版本貼上

2. **第二階段**：現在只有基礎方法不同，所以在 constructor function 為每個 basis 方法引入一個欄位，並且指定數值

3. **修改方法**：Change the method to the new column, instead of return a const.

4. **編譯驗證**：Compiling the code and verifying that everything is intact so far.

5. **對每個欄位執行以下步驟**：
   1. Copying the column's default value and then setting it as a parameter.
   2. Checking the compiler error and inserting the default value as an argument.

6. **刪除多餘類別**：刪除合併後的所有類別，保留其中一個，然後改用成這個類別，修正所有編譯器的錯。

### 範例：交通燈重構

#### 原始程式碼

```typescript
function nextColor(t: TrafficColor){
    if (t.color() == "red") return new Green();
    else if (t.color() == "green") return new Yellow();
    else if (t.color() == "yellow") return new Red();
}

interface TrafficColor {
    color(): string;
    check(car: Car): void;
}

class Red implements TrafficColor {
    color() { return "red" }
    check(car: Car) { car.stop(); }
}

class Yellow implements TrafficColor {
    color() { return "yellow" }
    check(car: Car) { car.stop(); }
}

class Green implements TrafficColor {
    color() { return "green" }
    check(car: Car) { car.drive(); }
}
```

#### 實作步驟

1. **識別 basis**：color 是 basis，因為每個類別都有 color 但是返回不同的常數

   a. 對 check 方法的每個版本，加上 if (true) {} 包住現有的程式碼

   ```typescript
   class Red implements TrafficColor {
       check(car: Car) {
           if (true) {
               car.stop();
           }
       }
   }
   
   class Yellow implements TrafficColor{
       check (car: Car){
           if (true){
               car.stop();
           }
       }
   }
   
   class Green implements TrafficColor {
       check (car: Car){
           if (true){
               car.drive();
           }
       }
   }
   ```

   b. 把它轉換成陳述句

   ```typescript
   class Red implements TrafficColor {
       check(car: Car) {
           if (this.color() === "red") {
               car.stop();
           }
       }
   }
   
   class Yellow implements TrafficColor{
       check (car: Car){
           if (this.color() === "yellow"){
               car.stop();
           }
       }
   }
   
   class Green implements TrafficColor {
       check (car: Car){
           if (this.color() === "green"){
               car.drive();
           }
       }
   }
   ```

   c. 然後把每個版本的方法都複製到一份，然後加上 else，並且複製貼到其他所有版本

   ```typescript
   class Red implements TrafficColor {
       check(car: Car) {
           if (this.color() === "red") {
               car.stop();
           }
           else if (this.color() === "yellow") {
               car.stop();
           }
           else if (this.color() === "green") {
               car.drive();
           }
       }
   }
   
   class Yellow implements TrafficColor{
       check(car: Car) {
           if (this.color() === "red") {
               car.stop();
           }
           else if (this.color() === "yellow") {
               car.stop();
           }
           else if (this.color() === "green") {
               car.drive();
           }
       }
   }
   
   class Green implements TrafficColor {
       check(car: Car) {
           if (this.color() === "red") {
               car.stop();
           }
           else if (this.color() === "yellow") {
               car.stop();
           }
           else if (this.color() === "green") {
               car.drive();
           }
       }
   }
   ```
    
2. **引入欄位**：現在只有基礎方法不同就是 color，所以在建構函式為 color 引入一個欄位，並指定常數值

   ```typescript
   class Red implements TrafficColor {
       constructor(private col: string = "red") {}
       color() {return "red"}
   }
   
   class Yellow implements TrafficColor {
       constructor(private col: string = "yellow") {}
       color() {return "yellow"}
   }
   
   class Green implements TrafficColor {
       constructor(private col: string = "green"){}
       color() {return "green"}
   }
   ```

3. **修改回傳值**：再來把回傳數值改成 this.col

   ```typescript
   class Red implements TrafficColor {
       constructor(private col: string = "red") {}
       color() {return this.col}
   }
   
   class Yellow implements TrafficColor {
       constructor(private col: string = "yellow") {}
       color() {return this.col}
   }
   
   class Green implements TrafficColor {
       constructor(private col: string = "green"){}
       color() {return this.col}
   }
   ```

4. **編譯驗證**：編譯，目前都沒有 Error

5. **參數化**：對每個類別的 col 進行下面的步驟
   
   a. 複製欄位的預設值，然後預設值變成參數

   ```typescript
   class Red implements TrafficColor {
       constructor(private col: string){}
   }
   ```

   b. 檢查編譯器的錯誤，並加預設值當作 argument

   ```typescript
   function nextColor(t: TrafficColor){
       if (t.color() === "red")
           return new Green("green");
       else if (t.color() === "green")
           return new Yellow("yellow");
       else if (t.color() === "yellow")
           return new Red("red"); // 以貼上的方式修復錯誤
   }
   ```

6. **統一類別**：所以現在每個類別一致過後我們可以刪掉其他類別保留一個就好了

   ```typescript
   function nextColor(t: TrafficColor){
       if (t.color() === "red")
           return new Red("green");
       else if (t.color() === "green")
           return new Red("yellow");
       else if (t.color() === "yellow")
           return new Red("red");
   }
   ```

function nextColor(t: TrafficColor){
    if (t.color() === "red")
        return new TrafficLight("green");
    else if (t.color() === "green")
        return new TrafficLight("yellow");
    else if (t.color() === "yellow")
        return new TrafficLight("red");
}

interface TrafficColor {
    color(): string;
    check(car: Car): void;
}

class TrafficLight implements TrafficColor {
    constructor(private col: string){}
    
    color() { return this.col }
    
    check(car: Car){
        if (this.color() === "red")
            car.stop();
        else if (this.color() === "yellow")
            car.stop();
        else if (this.color() === "green")
            car.drive();
    }
}
