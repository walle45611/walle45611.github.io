### Cloudflare Pull consumers
- **source link**: https://developers.cloudflare.com/queues/configuration/pull-consumers/
- **source**: raw/Cloudflare Pull consumers.md
- **核心概念**: Cloudflare Queues pull‑based consumer enables external systems to actively pull messages via HTTP and manage consumption with explicit ack/retry using lease_id.
- **重點**:
  1. Pull consumer requires HTTP API and explicit ack/retry; no automatic continuous consumption.
  2. Requires queues_read and queues_write permissions on API token.
  3. Default batch_size 5, visibility_timeout 30s (max 12h); adjustable.
  4. Supports multiple parallel consumers; each gets independent batch.
  5. Suitable when consumer not in Workers or needs strict throughput control.
