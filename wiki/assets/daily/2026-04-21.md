- 主題名稱：Cloudflare Pull consumers  
- source link： https://developers.cloudflare.com/queues/configuration/pull-consumers/  
- 1 句話核心概念：Pull‑based consumer 允許在 Workers 之外透過 HTTP 主動拉取訊息，並透過 lease_id 進行 ack/retry，提供更細緻的吞吐控制。  
- 3-5 個重點  
  1. Pull consumer 需要手動呼叫 pull API，並顯式 ack 或 retry，避免自動持續消費。  
  2. 需要 queues_read 與 queues_write 權限，因 ack 會改變 queue state。  
  3. visibility_timeout 可調整，避免過短造成重複投遞或過長拖慢失敗重試。  
  4. 支援多個並行 consumer，每個 consumer 取得獨立 batch。  
  5. Pull API 預設 batch_size 5、上限 100；visibility_timeout 30 秒、上限 12 小時。
