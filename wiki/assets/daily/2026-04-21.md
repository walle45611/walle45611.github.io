- 主題名稱：Cloudflare Pull consumers
- source link: https://developers.cloudflare.com/queues/configuration/pull-consumers/
- 1 句話核心概念：Pull-based consumer 讓訊息消費節奏改由外部系統主動控制，並透過 `lease_id`、ack、retry 與 `visibility_timeout` 管理處理生命週期。
- 3-5 個重點
  1. Pull consumer 由客戶端主動呼叫 API 拉取訊息，不會像 push consumer 那樣自動持續消費。
  2. Ack 與 retry 都屬於 queue state mutation，因此需要 `queues_read` 與 `queues_write` 權限。
  3. `lease_id` 是訊息 ack/retry 的核心憑證，未在 lease 期間 ack 會重新投遞。
  4. `visibility_timeout` 需要依實際處理時間調整，避免過短重複投遞或過長拖慢重試。
  5. Pull 模式更適合既有基礎設施、長任務或需要細緻控制吞吐的場景。
