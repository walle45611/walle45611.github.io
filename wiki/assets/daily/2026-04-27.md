  - source link: https://learn.microsoft.com/zh-tw/entra/fundamentals/what-is-entra

  - 涵蓋建立零信任存取控制、保護存取權限、外部與工作負載身份管理。

  - 提供 Microsoft Graph API 等工具用於自動化管理。
