    - 1 句話核心概念
      - Cloudflare Queues pull consumer allows external systems to actively pull messages, requiring explicit ack/retry and managing visibility_timeout.
    - 3 到 5 個重點
      - Pull consumer is an active pull model, not push.
      - Requires explicit ack/retry using lease_id.
      - Manages visibility_timeout to control message visibility.
      - Supports multiple parallel consumers with independent batches.
      - Pull API supports batch_size and visibility_timeout configuration.
