- Docker daemon socket 權限問題
  - source link: https://docs.docker.com/engine/install/linux-postinstall/
  - 1 句話核心概念：`permission denied while trying to connect to the Docker daemon socket` 通常表示目前使用者沒有存取 Docker Unix socket 的權限。
  - 重點：
    - Docker daemon 預設透過 Unix socket 提供本機存取，socket 通常由 root 管理。
    - 不想每次使用 `sudo` 時，可將使用者加入 `docker` group，重新登入或刷新 group membership 後再測試。
    - Docker 官方提醒 `docker` group 具有接近 root-level 的權限，不能把它當成一般低風險群組。
    - 若先前用 `sudo docker` 造成 `~/.docker` 權限錯置，還需要修正該目錄的 ownership / permissions。
