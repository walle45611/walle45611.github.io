- tmux `mouse` option 設定語法
  - source links:
    - https://github.com/tmux/tmux/wiki/Getting-Started
    - https://man7.org/linux/man-pages/man1/tmux.1.html
  - 1 句話核心概念：tmux 的 `mouse` 是 `on | off` 型態的 option，正確設定是 `set -g mouse on`，而不是 `set -g mouse=true`。
  - 重點：
    - tmux 官方 Getting Started 文件明確以 `set -g mouse on` 啟用滑鼠支援。
    - `mouse` 的合法值是 `on` 或 `off`，不是 shell-style 的 `true` / `false` 指派。
    - `set` 是 `set-option` 的別名；`-g` 表示設定 global option。
    - 因此 `invalid option: mouse=true` 的核心問題是把 option 名稱與值用 `=` 黏在一起，讓 tmux 把 `mouse=true` 當成不存在的 option 名稱。

- Docker Compose `--profile`、`up` 與 `--build` 參數層級
  - source links:
    - https://docs.docker.com/reference/cli/docker/compose/
    - https://docs.docker.com/compose/how-tos/profiles/
    - https://docs.docker.com/reference/cli/docker/compose/up/
  - 1 句話核心概念：`--profile` 是 `docker compose` 的全域 option，而 `--build` 與 `-d/--detach` 是 `docker compose up` 的 options，所以正確結構是 `docker compose --profile production up -d --build`。
  - 重點：
    - Docker Compose reference 將 `--profile` 列在 `docker compose` 本身的 options 中。
    - Profiles 文件示例使用 `docker compose --profile debug up`，確認 profile option 要放在 subcommand `up` 前。
    - `docker compose up` 文件把 `--build` 與 `-d, --detach` 列為 `up` 的 options，因此應放在 `up` 後。
    - `sudo docker compose --profile production up -d --build` 與把 `--build`、`-d` 對調都可；關鍵是它們都必須屬於 `up` 的參數區段。
