### Exponential function：數學結構與物理直覺

- website: NIST Digital Library of Mathematical Functions (DLMF)
- references:
  - https://dlmf.nist.gov/4.2
  - https://dlmf.nist.gov/4.7
- key findings:
  - DLMF 以冪級數定義 `exp(z)`：`1 + z/1! + z^2/2! + ...`。
  - 核心微分性質是 `d(e^z)/dz = e^z`，更一般地 `d(e^{az})/dz = a e^{az}`。
  - 因此 exponential 會自然出現在「變化率與目前狀態成比例」的模型；若 `dy/dt = ky`，其解具有 `e^{kt}` 形式。
- notes: `exp` 本身沒有單一固定的物理意義；物理意義取決於指數中的變數與模型。增長、衰減、放射性衰變、RC 電路等只是同一數學結構在不同系統中的實例。

### TLA+ 與 TLC model checking

- websites: TLA+ Foundation / TLA+ documentation / Leslie Lamport
- references:
  - https://github.com/tlaplus/tlaplus
  - https://docs.tlapl.us/using%3Atlc%3Astart
  - https://lamport.org/tla/tools.html
- key findings:
  - TLA+ 是用來設計、描述與驗證 reactive / concurrent systems 的 formal specification language。
  - TLC 是 TLA+ 的 explicit-state model checker，可對常見有限模型檢查 safety 與 liveness property，並在違反性質時提供 counterexample trace。
  - 官方工具 repository 目前將 CLI tools 與 VS Code extension 作為主要使用方式之一；Eclipse-based TLA+ Toolbox 仍可取得，但 repository 說明標示為目前未維護。
- notes: TLA+ 的重點不是直接證明某段 application code 完全正確，而是先把系統狀態、轉移與應滿足的 invariant / temporal property 形式化，再用 model checking 找設計層級的反例。

### ORCID biography 欄位與研究簡介

- website: ORCID Support
- reference: https://support.orcid.org/hc/en-us/articles/360006971513-Add-a-biography-to-your-ORCID-record
- key findings:
  - ORCID biography 是 plain-text 欄位，適合用敘事方式描述研究背景、研究方向與學術興趣。
  - biography 上限為 5000 characters，並可設定 Everyone、Trusted parties 或 Only me 的 visibility。
- notes: ORCID bio 比較適合保留主要研究主軸與較廣的技術背景，而不是把所有技能或工具逐項列成履歷式清單。
