### Better BibTeX for Zotero：自動匯出與 citation key

- https://retorque.re/zotero-better-bibtex/exporting/auto/
- https://retorque.re/zotero-better-bibtex/citing/
- 今日複習的工作流是：以 Zotero Collection 對應 LaTeX 專案，使用 Better BibTeX 匯出 `.bib`，勾選 `Keep updated` 後，collection 內容變動可觸發自動重新匯出。
- 官方文件指出 auto-export 可以針對不同 collection／paper 分別設定，避免每次手動重新 export 整個 library。
- citation key 是 LaTeX 文件與 bibliography 之間的穩定識別；Better BibTeX 提供 deterministic、避免衝突的 key 生成與使用者可控的 key 管理，比每次臨時從 BibTeX 匯出時才產生 key 更適合長期 LaTeX 專案。
- 實務筆記：若主要需求只是取得 BibTeX，而論文閱讀與筆記仍走紙本，Zotero + Better BibTeX 的核心價值集中在「collection 管理、穩定 citation key、`.bib` 自動同步」，不必把整套閱讀筆記流程搬進 Zotero。

### Microsoft Word：手寫簽名圖片與數位簽章

- https://support.microsoft.com/en-us/word/insert-a-signature-in-a-word-document
- https://support.microsoft.com/en-us/office/security-privacy/add-or-remove-a-digital-signature-for-microsoft-365-files
- Microsoft 官方支援將手寫簽名掃描或存成常見圖片格式後插入 Word；這種作法是在文件上放置簽名圖像。
- 數位簽章則是另一個概念，會牽涉 digital certificate、簽署者身分與文件完整性驗證；不能把單純的 PNG／JPG 手寫簽名圖片當成憑證式 digital signature。
- 今日實務情境偏向一般文件／申請資料中的簽名呈現，因此圖片式簽名與真正憑證簽章的差異是主要判讀點。

### Microsoft Outlook：Reply、Reply All、Forward 與附件

- https://support.microsoft.com/en-us/outlook/reply-to-or-forward-an-email-message
- `Reply` 只回覆原寄件者；`Reply All` 會回覆原寄件者以及原本 To／Cc 的其他收件人；`Forward` 則是把郵件轉寄給新的收件人。
- Microsoft 官方說明：回覆郵件時，原信附件不會自動附回；若要回傳修改後或新整理的檔案，需要在 reply 中重新加入附件。Forward 則會自動包含原信附件。
- 今日也檢視了回覆郵件下方的原信引用與附件回傳方式；公開紀錄只保留工作流層級結論，不保存實際郵件內容、姓名或附件名稱。
- 實務筆記：少量文件回傳時直接逐一附檔通常比 ZIP 更方便對方檢查；ZIP 比較適合檔案數量多、需要維持資料夾結構或整包交付的情境。這是工作流建議，不是 Outlook 的產品限制。

### Microsoft Word for Mac：表格中的 Tab 與多階層清單

- https://support.microsoft.com/en-us/accessibility/word/keyboard-shortcuts-in-word
- https://support.microsoft.com/en-us/word/set-tabs-in-a-table
- Word for Mac 在表格中按 `Tab` 會移到下一個儲存格；位於最後一列最後一格時，`Tab` 會新增一列，因此在表格裡不能把一般文件中的 `Tab` 行為直接當成清單降階。
- Microsoft 的 Mac 快捷鍵文件列出：在表格儲存格內插入真正的 tab character 可用 `Option+Tab`；但這只是插入 tab 字元，並不等同於把多階層清單降一層。
- 今日的實務重點是：表格內要調整多階層清單層級時，應改用 Word 的清單／段落縮排控制，而不是依賴 `Tab`，以免游標跳格或在表格尾端新增列。
