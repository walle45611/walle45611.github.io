### Kubernetes：自動擴縮不是部署後自動發生

- source link: https://kubernetes.io/docs/concepts/workloads/autoscaling/
- source link: https://kubernetes.io/docs/concepts/workloads/autoscaling/horizontal-pod-autoscale/
- 核心概念：Kubernetes 支援自動擴縮，但必須配置相應 autoscaler；單純部署 Deployment 並不代表會依負載自動增減 Pod。
- 重點：
  - HPA（HorizontalPodAutoscaler）是 Kubernetes API resource 與 controller，會根據指定 metrics 調整 Deployment、StatefulSet 等 workload 的 replica 數。
  - HPA 可依 CPU、memory 或 custom metrics 進行水平擴縮；threshold、min/max replica 等行為需要明確設定。
  - 垂直擴縮（VPA）與 Node autoscaling 是不同層次的機制，不能把「Kubernetes 有 autoscaling」理解成所有資源都會自動調整。
  - 今日討論的簡化結論可保留為：K8s 不會憑空自動擴展，autoscaling 仍需要配置與 metrics 支援。
