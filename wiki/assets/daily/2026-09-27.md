### Cisco STP / RSTP

- https://www.cisco.com/c/en/us/td/docs/switches/lan/c9000/lyr2-fwd/stp/stp-configuration-guide/m-stp.html
- https://www.cisco.com/c/en/us/support/docs/lan-switching/spanning-tree-protocol/24062-146.html
- https://www.cisco.com/c/en/us/td/docs/switches/datacenter/nexus3000/sw/layer2/503_U1_1/Cisco_n3k_layer2_config_gd_503_U1_1_chapter7.html

重點：
- STP 先選 Root Bridge，再由非 Root switch 選最佳 Root Port，各 segment 再決定 Designated Port。
- 802.1D topology change 會先通知 Root，再由 Root 以 TC flag 傳播；RSTP 改以 TC flag 快速擴散，不再依賴獨立 TCN BPDU。
- RSTP 在 point-to-point link 上以 proposal/agreement handshake 加速收斂；full-duplex link 預設可視為 point-to-point。
- link failure 後會重新計算 port role，可能重新選 Root Port / Designated Port。
- Hello BPDU 不只是存活檢查，也持續攜帶 Root、cost 與 port state/role 等控制資訊。

### Cisco CEF / FIB / TCAM

- https://www.cisco.com/c/en/us/td/docs/switches/lan/catalyst3850/isw-cef-xe-3se-3850-book.html
- https://www.cisco.com/c/en/us/support/docs/switches/catalyst-4000-series-switches/66978-tcam-cat-4500.pdf

重點：
- CEF 主要使用 FIB 與 adjacency table；FIB 是為 forwarding lookup 最佳化的路由資訊，adjacency 保存下一跳 Layer 2 rewrite 資訊。
- `punt` 表示封包需要特殊處理而送往較高層 switching / CPU path，不是正常每包都走的 forwarding 路徑。
- TCAM 是交換器硬體比對資源，可用於 ACL、QoS 等高速 lookup；實際用途與配置依 ASIC／平台而異。
- RIB 屬 control-plane 路由資訊，FIB 是 forwarding-plane 表示，不能把每個封包理解成「CPU 查 RIB 再查 FIB」。

## 知識串聯

今天的複習把 STP/RSTP 的控制平面收斂與 CEF/TCAM 的資料平面 forwarding 分開：前者決定二層無迴圈拓撲與 port role，後者關心封包如何以硬體資料結構高速轉送。
