### Linux namespaces：unshare / nsenter / network namespace

- https://man7.org/linux/man-pages/man1/unshare.1.html
- https://www.man7.org/linux/man-pages/man1/nsenter.1.html
- https://www.man7.org/linux/man-pages/man7/network_namespaces.7.html
- https://www.man7.org/linux/man-pages/man7/user_namespaces.7.html

重點：
- `unshare` 會依指定選項建立新的 namespace，然後在其中執行程式；可以一次建立多種 namespace。
- `-n` / `--net` 才會建立新的 network namespace；如果只建立 user namespace，process 仍會使用原本所在的 network namespace。
- network namespace 會隔離 network device、IPv4/IPv6 stack、routing table、firewall rules、socket/port 等網路資源。
- `nsenter` 讓 process 進入既有 process 或 namespace 檔案所代表的 namespace。
- user namespace 中的 UID 0／capabilities 有 namespace 範圍；不能把 namespace 內 root 直接等同 host root。

### autofs / automount

- https://man7.org/linux/man-pages/man8/automount.8.html
- https://man7.org/linux/man-pages/man5/auto.master.5.html
- https://www.kernel.org/doc/html/v6.9/filesystems/autofs.html

重點：
- autofs 是 on-demand automount 機制：路徑被存取時才觸發掛載，閒置後可自動卸載。
- `automount` 讀取 `auto.master` 與對應 map 來建立受 autofs 管理的 mount points。
- autofs 並不限於 network filesystem，但對 NFS 等可能延遲、暫時不可用或不希望開機時就掛載的檔案系統特別有價值。
- 和固定在開機流程處理的靜態 mount 相比，autofs 的核心差異是按需觸發。

### 臺灣汽車定期檢驗

- https://www.mvdis.gov.tw/m3-emv-cht/public/newsDetail?id=23228

重點：
- 監理機關提醒，一般汽車所有人原則上可在指定檢驗日前後 1 個月內辦理定期檢驗；通知明信片或簡訊只是提醒，逾期未檢仍可能受罰。
- 驗車前應確認常見安全項目，例如輪胎胎紋、各式燈光及車牌狀況；設備異常可能被要求改善或召回檢驗。
- 辦理檢驗時還要注意強制汽車責任保險有效期等文件／資格條件；實際適用規則仍以車種與現行監理規定為準。

## 知識串聯

今天的技術複習集中在 Linux 的隔離與掛載生命週期：namespace 決定 process 能看到與操作哪些系統資源，`unshare` 建立新的隔離邊界、`nsenter` 進入既有邊界；autofs 則處理檔案系統何時才實際掛載。兩者都不是單純「有／沒有權限」或「有／沒有 mount」的二元概念，而是把資源可見性、生命週期與操作時機拆開管理。
