### Gray code 與自然二進位序列

- reviewed: 今日檢視一張以 `0000, 0001, 0010, 0011, ...` 依自然二進位次序排列的圖，重點是判斷它是否屬於 Gray code。
- key finding: 標準 binary-reflected Gray code 的相鄰 codeword 只差 1 個 bit；自然二進位計數則可能在進位時同時改變多個 bit，因此單純按 `0, 1, 2, 3, ...` 的 binary representation 排列不等於 Gray code。
- useful note: 例如自然二進位 `0011 → 0100` 同時改變 3 個 bit，直接違反 Gray code 的相鄰 Hamming distance = 1 特徵。
- useful reference: MathWorks 的 Gray-coded modulation 說明指出相鄰 Gray-coded symbols 的 binary representation 只差 1 bit。
- source link: https://www.mathworks.com/help/comm/ug/digital-baseband-modulation.html
- useful reference: Wikipedia 的 Binary-reflected Gray code 條目整理了反射式建構法，並給出 `G(n) = n XOR floor(n/2)` 的常見轉換形式。
- source link: https://en.wikipedia.org/wiki/Gray_code
