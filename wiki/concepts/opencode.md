# OpenCode

OpenCode 是一個近期熱門的開源 AI 程式設計工具，在社群中常被視為「開源版的 [[claude-code]]」。

## 核心定位與優勢

根據社群與教學影片（如 [[opencode-detailed-guide]]），OpenCode 的主要優勢在於：
- **低門檻與免費資源**：提供開箱即用的免費模型，降低了新手接觸 AI 輔助開發的門檻。
- **高擴充性**：允許使用者透過配置，免費接入頂級的商業模型（例如 Gemini 3 Pro、Claude 4.5 Opus 等）。
- **進階 AI Agent 能力**：支援 Agent Skills、Subagent 以及 MCP (Model Context Protocol) 等進階特性，非常適合作為學習與實作 AI Agent 的平台。
- **無地域限制風險**：相較於 Claude Code，OpenCode 對中國使用者更友善，沒有限速或封號等困擾。

## 擴充生態

OpenCode 支援強大的外掛系統，其中「Oh My Open Code (OMO)」被認為是大幅提升使用體驗的超強插件。
