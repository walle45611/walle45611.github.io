## Summary

這篇資料結構筆記整理 Binary Tree 與一般 Tree 的差異、二元樹定義、常見類型、節點與高度相關性質，以及陣列、鏈結串列與走訪實作。

## Key Points

- Binary Tree 可以為空，且每個節點至多有左右兩個子樹；一般 Tree 與 Binary Tree 的 degree 和順序概念不同。
- 文章整理節點數、樹高與不同 Binary Tree 類型的基本性質與推導。
- 實作面涵蓋陣列與 linked list 表示法，以及常見 traversal 與範例題。
- 內容參考 CLRS 與 Horowitz 的資料結構脈絡，完整推導與程式碼保留在 Blog source。
