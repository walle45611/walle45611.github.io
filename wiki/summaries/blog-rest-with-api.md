## Summary

這篇文章區分 API 與 RESTful 架構，從 Client、Resource 與 Web API 的角色開始，整理 REST 的統一介面、無狀態、分層等架構約束與 URI 設計實務。

## Key Points

- API 定義軟體系統互相溝通時要遵循的規則，Client 可以是瀏覽器或其他程式。
- Resource 代表應用程式可操作的資料，API 提供存取與處理資源的介面。
- REST 強調統一介面、stateless、cacheable、client-server 與 layered system 等約束。
- 原文也整理 RESTful API 的可擴展性、彈性、獨立性與 URI 設計方向。
