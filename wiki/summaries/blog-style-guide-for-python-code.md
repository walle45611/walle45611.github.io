## Summary

這篇文章依 Python 官方 PEP 257 與 PEP 8 整理 docstring、縮排、行長、運算子換行、import、命名與空白等程式碼風格規範。

## Key Points

- PEP 257 關注 module、function、class 與 method 的 docstring 位置與格式。
- PEP 8 涵蓋四個空格縮排、避免混用 Tab、行長、續行與運算式排版。
- 後半段整理 import、命名規則、方法參數與 whitespace 的常見寫法。
- 這是依當時官方文件整理的個人筆記；實際專案仍應以團隊 formatter/linter 合約為準。
