## Summary

這篇文章記錄以 VS Code Profile 分開不同框架與前後端工作所需的 extensions，並以 Default profile 作為其他 profile 的基礎，減少啟動與管理負擔。

## Key Points

- 不同專案不必共用同一組 extensions，可用 profile 分離工具集合。
- Default profile 可以保存常用工具，再以 copy from 建立新的工作環境。
- Profile 也可以建立、切換或刪除，讓 VS Code 啟動時載入較小的設定集合。
