## Overview

OpenAI’s Codex pricing has shifted from per‑message to token‑based rates as of April 2026. The new rate card applies to **ChatGPT Plus, Pro, Business, and new Enterprise** customers, while legacy rates remain for existing Enterprise/Edu customers.

### Token‑Based Pricing

| Model | Input Tokens | Cached Input | Output |
|-------|--------------|--------------|--------|
| GPT‑5.4 | 62.50 credits | 6.25 credits | 375 credits |
| GPT‑5.4‑Mini | 18.75 | 1.875 | 113 |
| GPT‑5.3‑Codex | 43.75 | 4.375 | 350 |
| GPT‑5.2 | 43.75 | 4.375 | 350 |
| GPT‑Image‑1.5 | 200 | 50 | 800 |
| GPT‑Image‑5.1 | 125 | 31.25 | 250 |

*Fast mode* consumes twice the credits. Code review uses GPT‑5.3‑Codex. Research preview models (e.g., GPT‑5.3‑Codex‑Spark) have provisional rates.

### Legacy Rate Card

Legacy rates still apply to existing Enterprise/Edu customers. OpenAI will migrate them to the new token‑based rates in the coming weeks.

### Practical Notes

- Average cost: **$100‑$200 per developer per month** (varies by model, usage, and fast mode).
- Monitor usage via Codex settings → **Usage** panel.
- Refer to OpenAI’s documentation for best practices on rate limits and token optimization.

For full details, see the official [Codex rate card](https://help.openai.com/en/articles/20001106-codex-rate-card).
