## Source Notes

- 可用於 Array (隨機存取) 或 Linked List (順序存取)。
- 假設機率平均分布：$\frac{1 + 2 + \dots + n}{n} = \frac{(n+1)}{2}$
- 所以平均需要 $\frac{n+1}{2}$ 次比較，仍為 $O(n)$。
