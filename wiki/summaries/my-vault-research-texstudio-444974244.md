## Source Notes

- 給教授快速閱讀與修改論文使用。以下以 Windows 的 TeXstudio 畫面為例，假設已安裝 MiKTeX 與 TeXstudio，並收到完整的論文資料夾。
- 安裝與範本請看 IEEE LaTeX 範本安裝與使用指南；公式、表格與引用語法請看 LaTeX 論文協作使用指南。
- 在 TeXstudio 選擇 File → Open…，或按 Ctrl + O。
