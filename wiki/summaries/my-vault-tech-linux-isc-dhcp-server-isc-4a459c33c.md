## Source Notes

- DHCP (Dynamic Host Configuration Protocol) 是一種網路協定，用於自動分配 IP 位址和其他網路設定給網路設備。本指南將介紹如何在 Linux 系統上設定 ISC DHCP Server 和 DHCP Relay。
- DHCP Relay 用於轉發不同子網路間的 DHCP 請求。
