## Summary

原筆記涵蓋 繞過網路連線要求、方法一：OOBE 繞過指令、使用步驟、方法二：中斷網路連線、繞過 TPM 和 Secure Boot 要求、註冊表修改方法。

## Source Notes

- Windows 11 對硬體有較嚴格的要求，包括 TPM 2.0、Secure Boot 和網路連線等。在某些情況下（如測試環境、舊硬體或實驗室環境），可能需要繞過這些限制來進行安裝。
- 在 Windows 11 安裝過程中，當系統要求連接網路時
- 到達網路設定畫面：在 Windows 11 安裝過程中，當看到「讓我們為您連接到網路」畫面時
