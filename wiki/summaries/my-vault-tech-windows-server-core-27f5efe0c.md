## Source Notes

- Windows Server Core 是 Windows Server 的最小化安裝選項，提供無圖形使用者介面的伺服器環境。它具有較小的攻擊面、更低的資源消耗，以及更少的維護需求，適合用於專門的伺服器角色部署。
- Windows Server Core 可以支援以下主要服務和角色
- ADCS (Active Directory Certificate Services) - 憑證服務
