## 摘要
這份文件介紹了近期熱門的 AI 程式設計工具 **OpenCode**。影片指出 OpenCode 實質上可視為「開源版的 Claude Code」，不僅具備其幾乎所有功能，而且對中國使用者更加友善（沒有限速、封號等問題）。最大的亮點在於開箱即用的免費模型，同時能透過配置免費接入頂級模型（如 Gemini 3 Pro、Claude 4.5 Opus）。

## 關鍵主張與特色
- **免費與頂級模型接入**：內建可免費使用的主流模型，並支援簡單配置接入 Gemini 3 Pro 與 Claude 4.5 Opus 等頂級模型。
- **Claude Code 替代品**：具備 Claude Code 的幾乎一切功能，被認為是其強大的開源平替方案。
- **進階特性**：支援 Agent Skills, MCP (Model Context Protocol), Subagent 等高階 AI 代理特性，適合用來練習。
- **友善度**：對中國使用者友善，免除限速與封號風險，適合新手無痛入門。
- **強大外掛**：特別提及了「Oh My Open Code (OMO)」這款超強外掛插件。
- **多種形態與環境**：介紹了 OpenCode 的四種形態與雲端環境的搭配用法。
