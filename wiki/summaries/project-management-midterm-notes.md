# 專案管理考前複習筆記講義

## Summary

這份筆記是一份明確以考前衝刺為目標的專案管理複習講義，採用「錯題分布優先級 -> 主題拆解 -> 速讀整理 -> 自測題」的結構，先集中補強組織結構與人員管理，再整理 PERT / network diagram / critical path 等時程計算題，最後補上 Kanban、User Story Map、逐步精進完善與其他常考名詞。

## Core Structure

1. 先按錯題分布排序複習優先度，把組織 / 人員管理列為最優先，其次是時程計算與網路圖，再來是敏捷與逐步精進。
2. 主體內容以主題式講義整理核心定義、判斷口訣、常見陷阱與考題識別訊號。
3. 後段加入錯題導向總複習表與考前 30 分鐘速讀版，壓縮成可快速回想的最小知識單位。
4. 最後用 10 題自測題檢查是否能把概念轉成題目判讀，而不是只停留在閱讀。

## Key Topics Covered

- 組織結構與人員管理：功能型、專案型、矩陣型組織，雙重回報，RACI，以及 Maslow 需求層次。
- 時程與估算：三點估計、PERT 公式、三角分配、network diagram、critical path、float / slack、crashing、fast tracking、resource leveling、resource smoothing。
- 敏捷與需求整理：Kanban、WIP、User Story、User Story Map、Progressive Elaboration、Rolling Wave Planning。
- 其他高頻考點：專案與作業差異、專案黃金四角、議題 / 變更 / 風險、溝通管道公式、應變準備金與管理準備金、EVA 基本公式。

## Notable Characteristics Of This Source

- 這不是單純抄錄課本，而是依「錯題熱區」重排的應試型筆記，強調先補最容易失分的概念群。
- 多數段落都搭配一句話記法、情境判斷或易混淆對照表，方便在短時間內做考前回想。
- 內容明顯以題目辨識為導向，例如看到 PERT 就要想到 `M × 4`、看到矩陣組織就要想到雙重回報與協調，而不是死背定義。
- 末段自測題把重點轉成快速判斷題，讓這份筆記同時兼具講義與自我檢核用途。

## Practical Takeaways

- 若要把大範圍考科壓縮成短時間可複習內容，先從錯題分布決定優先順序，比平均讀完所有章節更有效。
- 對管理與流程型考科，表格化對照與一句話口訣特別適合處理易混概念。
- 將定義、陷阱、題型訊號與自測題放在同一份筆記中，可以降低考前來回切換資料的成本。
